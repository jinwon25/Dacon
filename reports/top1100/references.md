# External methodology references

These references were used as hypotheses, not as evidence that a method improves this competition.

- [CatBoost / ordered target statistics (NeurIPS 2018)](https://proceedings.neurips.cc/paper/2018/hash/14491b756b3a51daac41c24863285549-Abstract.html) — motivated categorical-safe challenger; fixed outer iterations were used and the screen was rejected.
- [TabM repository](https://github.com/yandex-research/tabm) and [ICLR 2025 paper](https://proceedings.iclr.cc/paper_files/paper/2025/file/c1ba41c694834aeef91ae161711d4939-Paper-Conference.pdf) — motivated a parameter-efficient MLP pilot; package/runtime pilot remains deferred because prerequisite screens failed.
- [TabR / ICLR 2024](https://proceedings.iclr.cc/paper_files/paper/2024/hash/4ef594af0d9a519db8fb292452c461fa-Abstract-Conference.html) — motivated train-only constrained retrieval; full retrieval was not deployed and Trackman linkage failed placebo separation.
- [Pitching kinematics variability](https://pubmed.ncbi.nlm.nih.gov/31449438/) and [release-point variability](https://pmc.ncbi.nlm.nih.gov/articles/PMC11608975/) — motivated repeatability features; no physical feature was promoted without target-free identity evidence.
- [Context-enhanced pitch location](https://link.springer.com/article/10.1007/s12283-025-00497-5) — treated as a context/intent hypothesis only; the supplied schema has no plate coordinates, so no plate-location geometry was claimed.

No external baseball data or API was joined to the competition data.
