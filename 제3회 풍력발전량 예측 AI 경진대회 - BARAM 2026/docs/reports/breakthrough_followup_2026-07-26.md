## 대회 규정 적합성 판단

공식 규정은 각 예측기준시점 전에 생성·공개·확정되어 실제로 활용 가능했던
정보만 허용한다. 예보는 대상 시각이 아니라 공개 시각으로 판단하며,
관측자료도 예측기준시점 전에 관측·공개된 과거 자료만 허용한다. 외부
데이터는 공개 접근성, 라이선스, 누수 방지, 출처와 수집 절차의 재현성을 모두
충족해야 한다.

현재 승격 후보는 다음 이유로 이 기준에 부합한다고 판단한다.

1. KMA APIHub의 공개 operational UMRG/N512와 UMKR/N512 예보자료만
   원자료로 사용한다.
2. UMRG는 12시간, UMKR는 9시간의 보수적 공개 지연을 적용한다. 실제
   UMKR의 최소 공개 여유는 60분이고 모든 행의 타이밍 위반은 `0`건이다.
3. 2025 UMKR API가 호스트 타임아웃으로 응답하지 않아, 2023의 공개
   UMRG–UMKR 날씨쌍만으로 로컬 Ridge 다운스케일러를 학습했다. 2025
   대리 피처는 이미 규정 검사를 통과한 2025 UMRG에서 로컬 생성한다.
4. 2023 라벨로 2024를 예측하여 구조를 검증한 뒤, 같은 고정 구조로 2024
   라벨을 학습하고 2025를 추론한다.
5. 평가구간 발전 실측, 사후 관측, 재분석자료, 비공개 운영자료는 사용하지
   않는다.
6. 발전량 모델은 로컬 LightGBM, 날씨 다운스케일러는 로컬 Ridge로
   학습·추론한다. KMA API는 공개
   기상자료의 수집 경로이며 OpenAI·Gemini 같은 원격 모델 추론 API로 모델
   응답을 받은 것이 아니다.
7. 원본 URL의 인증키는 모두 제거하고, 출처·수집시각·체크섬·사용기간·변수와
   전처리 코드를 보존한다.

따라서 공식 규정의 외부 데이터 조항과 API 기반 **원격 모델 추론 금지**

## 새 방법론 검증 결과

### 1. KMA 동·중·서 공간 문맥

동쪽·중앙·서쪽 UMRG 세 지점의 평균, 표준편차, 동서 기울기를 사용했다.
2023에서 학습해 2024를 예측하고 기존 단일지점 전문가와 같은 alpha, weight,
seed, 이동 상한을 유지했다. 그룹 1과 그룹 3 모두 H1에서 탈락했다. 2025
공간자료와 제출 CSV는 만들지 않았다.

### 2. 공식 점수 기대효용 Bayes action

조건부 분위수 분포에서 10% 평가 자격과 6%·8% FICR 절벽을 직접 반영해
행별 기대 공식 점수를 최대화했다.

- 그룹 1: H1 탈락
- 그룹 2: H1 통과 후 H2 FICR `-0.000229`, 양의 월 6/12,
  부트스트랩 5% 하한 음수로 탈락
- 그룹 3: H1 score `+0.001350`, H2 score `+0.000895`였지만 H2
  1-NMAE `-0.000307`, 양의 월 4/12, 모든 안정성 게이트 실패

세 그룹 모두 생산 정책과 CSV를 만들지 않았다.

### 3. ASOS 관측과 KMA MOS 편향 보정

공개 ASOS 관측을 120분 지연시켰고 위반은 `0`건이었다. 원시 관측 변수를
직접 추가한 모델, ASOS와 동일 유효시각의 KMA 10m 바람 차이를 이용한
물리적 MOS 보정, 최종 발전량 잔차 보정을 각각 시험했다.

그룹 1 MOS 잔차 보정은 Q2·H2 평균이 양수였지만 무관측 대조모형보다 FICR이
낮고, 11월과 발행주기 부트스트랩 5% 하한이 음수였다. 그룹 2·3도 구간별
방향이 바뀌었다. ASOS는 현재 구조에서 안정적인 추가 신호로 입증되지
않았으므로 생산 후보에 포함하지 않았다.

### 4. 적격 발전량 전용·계절 전문가·CatBoost 분위수

- 10% 이상 발전량만 학습하는 조건부 모델은 단독 점수는 좋아졌지만 현재
  후보와 비교할 때 NMAE가 악화했다.
- 전년도 동일 계절만 학습하는 모델은 그룹 1 Q2 `-0.007216`, 그룹 3 H1
  `-0.001538`로 탈락했다.
- CatBoost 분위수 전문가는 LightGBM과 약 0.92의 높은 상관을 보였고,
  혼합 시 H1 또는 H2가 악화해 다양성 이득을 입증하지 못했다.

### 5. 1.5km UMKR 다중 해상도 전문가

공식 문서상 UMRG는 12km, UMKR는 1.5km이며 UMKR의 00·06·12·18UTC
초기장은 48시간 예측을 제공한다. 9시간 보수적 지연과 최신 초기장 하나를
사용하면 다음날 24시간 전체를 덮고 기준시각보다 60분 앞선다.

- UMRG에서는 세 그룹 좌표가 같은 격자였지만 UMKR에서는 그룹 1과
  그룹 3이 다른 격자로 구분됐다.
- UMKR 단독 G1은 Q2와 부트스트랩에서 실패했다.
- UMRG+UMKR G1은 전기간 `+0.005300`, 10/12개월 양수,
  부트스트랩 q05 `+0.001454`로 통과했다.
- G3는 실제 좌표와 서쪽 스텐실을 결합했을 때 전기간 약 `+0.003481`로
  통과했지만, 2025 UMKR API 타임아웃 때문에 그대로 생산하지 못했다.
- G2는 전기간 양수였어도 Q1과 부트스트랩 하단이 음수라 폐기했다.

### 6. 로컬 UMRG→UMKR 다운스케일러와 배포 대칭 검증

원격 모델 API를 사용하지 않고 Ridge를 로컬 실행했다. 2023 Jan–Sep
날씨쌍으로 학습한 2023 Q4 홀드아웃의 중앙 피처 상관은
`0.939~0.948`, 중앙 정규화 RMSE는 `0.337~0.353`이었다. 최종
다운스케일러는 2023 전체 날씨쌍으로만 다시 학습하고 같은 모델을
2023·2024·2025 UMRG에 적용했다.

- 대리 피처만 사용한 G1·G3는 안정적이지만 기존 최고보다 낮았다.
- 실제 2023 UMKR 학습→대리 2024 UMKR 검증은 G1에서 실패했다.
- 같은 하이브리드는 G3에서 전기간 `+0.003338`과 모든 안정성 게이트를
  통과했다.
- 생산도 검증과 대칭으로 실제 2024 UMKR 학습→대리 2025 UMKR 예측을
  사용한다.

## 블렌딩에 대한 객관적 판단

구간별 강세 모델을 섞는 발상 자체는 타당하다. 그러나 이 대회에서 구간
강세는 실제 정답을 본 뒤에만 식별되는 경우가 많았고, 강세 구간을
예측시점 정보만으로 재현하는 gate가 Q1→Q2와 H1→H2에서 반복적으로
무너졌다. 따라서 현재는 다음 두 경우만 블렌딩한다.

1. 전년도 전체에서 학습한 독립 전문가가 2024 Q1·Q2·H2에서 모두 세 지표를
   개선하고 월별·시드·발행주기 부트스트랩을 통과한 경우
2. 서로 다른 그룹에 작용하여 간섭이 없는 경우

이 원칙으로 그룹 1과 그룹 3의 year-forward KMA 전문가만 결합했고, 그룹
2는 공개 최고점의 값을 보존했다. 정답을 알아야 선택할 수 있는 월별
마스크나 H2 사후 gate는 적용하지 않는다.
