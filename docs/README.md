## 먼저 이해할 용어

| 용어 | 이 프로젝트에서의 뜻 |
|---|---|
| Public / Private 점수 | 리더보드의 공개·비공개 평가 구간 점수입니다. 공개 점수 개선을 전체 평가 성능으로 확대하지 않습니다. |
| CV / holdout | 자료를 나눠 모델을 검증하는 방법 / 따로 남긴 평가 표본입니다. |
| OOF | 각 행을 학습에 사용하지 않은 모델의 예측입니다. 시간 순서·분할 방식·후처리 재사용 여부도 함께 확인합니다. |
| ASOF | 예측 시점까지 알 수 있는 정보만 사용한다는 기준입니다. |
| 기준 모델 / 블렌드 | 비교의 출발점인 모델 / 여러 예측을 가중 결합한 결과입니다. |
| 게이트 / 승격 | 적용 조건 또는 검증 통과 조건 / 후보를 선택된 버전으로 바꾸는 결정입니다. |
| MAE / SMAPE | 평균 절대 오차 / 상대 오차를 정규화한 지표입니다. 낮을수록 좋으며 대회별 산식을 확인합니다. |
| BSS | Brier Skill Score. 기준 예측 대비 확률 오차 개선을 나타내는 지표이며, 투구 대회의 점수 표기를 따릅니다. |
| 재조립 / 재학습 | 저장된 자산으로 패키지를 다시 만드는 작업 / 데이터로 모델을 새로 학습하는 작업입니다. |
| 프로토타입 | 기능과 흐름을 확인한 구현입니다. 실제 경기 결과 예측·운영 효과 검증과 구분합니다. |

## 공개본의 읽기 기준

코드·집계 보고서·출력이 제거된 노트북을 공개합니다. 원본 데이터·모델·OOF·제출 ZIP은 포함하지 않습니다. 과거 제출 패키지의 경로·명령은 연구 기록으로 남아 있으며 공개 clone에서 바로 실행되는 명령으로 읽지 않습니다. [공개 검토 기록](../.github/PUBLICATION.md)에서 제외한 자산과 검증 범위를 확인합니다.
