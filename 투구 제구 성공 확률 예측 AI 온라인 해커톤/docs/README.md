## 먼저 이해할 용어

| 용어 | 이 프로젝트에서의 뜻 |
|---|---|
| R / F | 대회 제공 자료를 나누는 도메인 구분입니다. 임의로 다른 구분이나 공통 선수 식별자로 해석하지 않습니다. |
| R_CORE / R_ANCHOR | R 도메인을 나눈 내부 경로 이름입니다. 경로별 변경 범위와 보호 조건을 함께 확인합니다. |
| TrackMan 연결 | 서로 다른 자료의 투수 프로필을 연결하는 연구입니다. 유사도·연결 신뢰도가 선수 신원 확정을 뜻하지 않습니다. |
| OOF / ASOF | 학습 외 예측 / 예측 시점까지의 정보 사용 기준입니다. 생성 계보와 시점을 함께 확인합니다. |
| Brier / BSS | 확률 예측의 제곱 오차 / 기준 예측 대비 개선 점수입니다. Brier는 낮을수록, 이 대회의 BSS 표기는 높을수록 좋습니다. |
| champion / challenger | 당시 선택된 기준 버전 / 새 후보입니다. 최종 선택은 v345입니다. |
| screen / gate | 탐색용 빠른 비교 / 사전에 정한 통과 기준입니다. 탐색 점수만으로 최종 성능을 확정하지 않습니다. |
| exact / frozen | 비교 대상의 계산·계보를 맞춘 상태 / 조건이나 자산을 고정한 상태입니다. 독립 평가 여부와는 별개입니다. |
| 행 독립성 | 입력 행 순서·묶음 크기가 달라도 같은 행의 예측이 유지되는 조건입니다. |
| 재현 ZIP | 제출 환경에서 실행하던 패키지입니다. 공개 저장소에서는 ZIP과 모델을 제외했습니다. |

## 해석 기준

로컬 검증, 공개 점수, 본선·수상 결과를 구분합니다. 반복 사용한 2024 개발 구간은 새로운 독립 확증 표본으로 소개하지 않습니다. 영문 실험 원문은 당시 수치·판정의 근거로 보존하며 한국어 안내에서 먼저 맥락을 확인합니다.
