# 1170 후속 연구: 팀 OOF 계약과 환경 안정 잔차 — 2026-08-22

## 결론

현재 champion은 Public `1158.0745556751`의 standalone ZIP으로 유지한다. v77은 팀원
모델을 동일 행 exact temporal OOF에서 안전하게 비교·혼합할 수 있는 계약과 constrained
blend evaluator를 완성했다. 그러나 현재 브랜치와 로컬 artifact에는 champion과 독립적인
팀원 final OOF가 없어 실제 blend weight는 계산하지 않았다.

독립 OOF가 없을 때 실행하기로 사전등록한 v78 환경 안정 잔차 모델은 기각했다. 두 primary
축 모두 source cross-fit에서 비영 보정을 선택하지 못해 `eta=0`으로 종료됐다. 2023 내부에서
게이트를 통과한 보정도 2024 역사 감사축에서 Brier-equivalent gain `-7.5362`로 반전했다.
따라서 ZIP과 Public probe는 만들지 않았다.

## v77: 팀 exact OOF 전달 계약

구현 파일은 다음과 같다.

- 계약: `configs/oof_bundle_contract_v1.json`
- 검증·혼합: `src/archive/v77_team_oof_constrained_blend.py`
- 테스트: `tests/test_v77_team_oof_constrained_blend.py`

각 bundle은 `row_id`, `axis`, `evaluation_season`, `target`, `prediction`, `domain3`,
`month`, `pitcher_id`, `batter_id`를 담은 CSV와 manifest를 제공해야 한다. evaluator는 다음을
기계적으로 막는다.

- CSV·모델·원본 학습 데이터 SHA-256 불일치
- `(axis, row_id)` 중복, target·domain·month·ID 또는 행 집합 불일치
- 평가 시즌 이상을 학습에 사용한 축
- test 집계, Public 점수 기반 weight, 비행독립 후보
- incumbent와 동일 모델 hash인 가짜 다양성 후보

혼합식은 `p = p0 + Σ alpha_j (pj - p0)`이고 `alpha_j >= 0`, `Σ alpha_j <= 1`이다.
source의 전체·월·domain Brier 비악화 제약을 두며, 영 가중치는 항상 feasible하다. 이 결과만으로
Public 자격을 부여하지 않고 평가 v3의 outer evidence, bootstrap과 Reality Check를 별도로
요구한다.

## v78: 환경 안정 trajectory residual

사전등록 파일은 `configs/v78_environment_stable_residual.json`이다. test CSV는 읽지 않고,
현재 행의 pre-pitch 정보와 origin 이전 train에서 동결된 ASOF·TrackMan profile만 사용했다.
선수 ID, 현재 투구 물리·위치, 다른 test 행 집계는 feature에서 제외했다.

28개 저용량 feature는 세 family로 고정했다.

- 최근 1/3/5경기 대비 장기 성공률·중간 제구율의 차이, 기울기, 곡률
- 투수·타자·구종 표본 신뢰도, strike-ball 및 middle-reverse margin, 구종 entropy
- count, 주자, 이닝, 점수차, LI, 승리기대차, 좌우 matchup과 제한된 상호작용

환경은 target을 사용하지 않은 `domain3 × 월 band(early/mid/late)`다. 각 환경의 incumbent
residual 평균을 제거해 domain/month base-rate lookup을 전달하지 않았고, source 환경의 75%
이상에서 계수 부호가 같은 feature만 Ridge에 남겼다. risk는 uniform, environment-equal,
worst-third 세 종류, eta는 `0, 0.25, 0.5, 1.0`으로 실행 전 고정했다.
