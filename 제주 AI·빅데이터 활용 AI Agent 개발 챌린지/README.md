# 제주 AI·빅데이터 활용 AI Agent 개발 챌린지

**물어봅서**는 제주 관광·소비·교통 데이터를 일상 언어로 물어볼 수 있게 만든 개인 제출작입니다. 예를 들어 “지난해 같은 기간보다 내국인 관광객의 카드 소비가 얼마나 달라졌어?”라고 물으면, 두 기간의 소비액을 비교하고 어떤 데이터와 계산식으로 답을 얻었는지 보여줍니다.

## 접근 방법

- **질문 해석** — 질문에서 지표와 기간, 비교 대상을 찾습니다. 규칙만으로 뜻이 불분명하면 로컬 언어 모델이 해석을 보완합니다.
- **분석과 근거** — 해석한 조건을 검증한 뒤 DuckDB에서 집계합니다. 답변에는 결과표와 함께 데이터 출처, 집계 기간, 실제 사용한 SQL을 표시합니다.
- **결과 해석** — 일부 날짜만 집계된 달이나 집계 기준이 달라졌을 가능성이 있는 구간을 표시해 전년 대비 수치를 읽을 때 참고할 수 있게 했습니다.
